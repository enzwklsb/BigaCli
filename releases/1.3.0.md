# BigaCli 1.3.0

Windows x64 · CloudCLI 1.37.3 · Codex 0.159.3 · Node.js 24.19.0

## 中文

- 手机和平板新增电脑桌面入口，可局部缩放、拖动并手动操作 Windows 授权弹窗。首次启用仍需在电脑端允许安装。电脑浏览器不显示该入口。
- 电脑桌面采用统一弹窗卡片，点击遮罩关闭；不会自动向对话发送消息。
- 权限页仅保留选项，完整访问使用红色文字和图标。不会更改 Codex 权限或解除策略限制。
- 改善弱网下账号授权、新对话与模型设置读取的恢复；首次发送前隐藏工作树中的草稿。
- 修复部分会话刷新后的重复用户消息。账号额度全部耗尽时，选择最早恢复额度的兼容账号等待。
- 文件预览支持在电脑上打开或运行，成功后关闭预览。

已有安装：设置 → 检查更新。首次安装下载 **BigaCli-win-x64.zip**，解压后运行 `start.cmd`。跨网络访问请使用自己的 Tailscale 等私有网络，电脑需保持运行。

## English

- Phones and tablets can open the host desktop, pinch to zoom locally, pan, and manually interact with Windows prompts. Initial setup still requires approval on the computer. Desktop browsers hide this entry.
- The desktop viewer uses the shared popup card; tap outside to disconnect. It does not send chat messages.
- Simplified permission choices, with full access highlighted in red. Codex permissions and policy restrictions are unchanged.
- Better recovery for account sign-in, draft initialization and model setup on unstable networks. Workspace drafts remain hidden until the first send.
- Fixed duplicated user messages in some reloaded conversations. When compatible accounts are exhausted, wait on the account whose quota recovers first.
- Open or run previewed files on the host, closing the preview after a successful request.

Update in Settings → Check for updates. New users: extract **BigaCli-win-x64.zip** and run `start.cmd`. For cross-network access, use your own private network such as Tailscale and keep the host running.

## 日本語

- スマートフォン・タブレットからパソコンのデスクトップを表示し、画面内の拡大・移動、Windows 確認画面の手動操作が可能です。初回の有効化には PC 側の承認が必要です。PC ブラウザーでは入口を表示しません。
- 共通ポップアップを採用。カード外のタップで切断し、会話へメッセージを自動送信しません。
- 権限選択を簡素化し、フルアクセスを赤色表示。Codex の権限やポリシー制限は変更しません。
- 不安定な通信での認証・新規会話・モデル設定の復旧を改善。初回送信前の下書きは一覧に表示しません。
- 一部会話の発言重複を修正。全候補が利用枠上限に達した場合、最も早く回復する対応アカウントで待機します。
- プレビューから PC 上のファイルを開く・実行する操作に対応。

既存環境は設定から更新できます。初回は **BigaCli-win-x64.zip** を展開して `start.cmd` を実行してください。外出先からは Tailscale など自身のプライベートネットワークを使用し、PC を起動しておいてください。
