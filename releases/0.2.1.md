BigaCli 0.2.1：打开即用，无需 CloudCLI 网页账号。

- 删除网页登录、注册表单和浏览器 token 门禁；工作区、Codex 账号、WebSocket 和检查更新直接可用。
- 保留已有内部用户、偏好及对话；空数据库自动创建内部用户。Codex 账号认证不变。
- 检查更新失败时明确显示错误，不再与“已是最新版”混为一谈；工作区失败时不再停留在“加载中”。
- 3101 可达的设备均可直接使用。本轮不增加组网或远程连接功能。
- 从 0.2.0 更新仅下载约 7 MB 的应用组件，复用现有 CloudCLI 1.37.3 / Codex 0.153.4 依赖和 Node。

这是组件更新版本，不重新制作完整安装包。首次安装可下载 [0.2.0 完整包](https://github.com/enzwklsb/BigaCli/releases/download/v0.2.0/BigaCli-win-x64.zip)，启动后在页面更新到本版。
