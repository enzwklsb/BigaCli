BigaCli 0.2.0：Astra、动态模型、速度切换和表格。

- 升级为 CloudCLI 1.37.3，以及其锁文件指定的 Codex SDK / CLI 0.153.4。
- 模型和思考档位读取当前对话账号的原生 model/list，不再依赖静态模型名单。切换账号后重新加载。
- 模型菜单新增普通 / 快速，默认普通；选择保存在当前浏览器的该对话设置中。每次发送明确传递速度，快速模式会消耗更多额度。
- 用 CloudCLI 已有的 ReactMarkdown 与 remark-gfm 替换简易 Markdown 解析。支持表格、流式表格、链接和代码，宽表格可横向滚动。
- 保留多账号隔离、流式回复、历史时间与消息分类。
- 修正账号、模型和额度查询结束时强杀 CLI 导致的偶发数据库初始化失败，改为正常关闭并等待退出。
- 从 0.1.0 点击一次“下载并更新”，下载变更的应用和依赖组件，复用原 Node；任务结束后自动重启并恢复页面。

首次安装下载 BigaCli-win-x64.zip，解压后运行 start.cmd。源码与构建脚本见本版本标签，AGPL-3.0-or-later。

维护者发布此草稿后，已安装 0.1.0 的用户才会收到更新提示。
