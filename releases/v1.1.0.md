# BigaCli 1.1.0

This release brings the locally tested browser, account recovery and mobile workflow improvements into one public update.

- Connect everyday Chrome or Edge through the official Playwright extension and use existing website logins. Independent Chromium remains a backup option.
- Connect GitHub from Settings, authorize in the browser on your phone or computer, switch accounts, and sign out. GitHub CLI must be installed on the host PC.
- Switch Codex accounts immediately while preserving the choice to resume automatically. Restored quota unlocks the composer without a page refresh, and automatic mode explains when no eligible account is available.
- Show account status read errors without incorrectly reporting every account as signed out; report disk-space failures clearly.
- Smooth streamed replies and reasoning with approximately one second of display buffering. Reasoning no longer has an internal height limit. Fix bold Markdown next to punctuation and simplify the file download control.
- Use a foreground service window for both ZIP and npm startup. Closing that window stops BigaCli.
- Bundle Codex CLI / SDK / Windows Runtime **0.159.3**. Model availability still depends on the signed-in account and the catalog returned by Codex.

**Download:** `BigaCli-win-x64.zip` is the complete Windows x64 package with Node.js included. Extract it and run `start.cmd`. Existing installations can update through Settings → Check for updates; let active tasks and account recovery finish first.

**Browser setup:** install the [official Playwright extension](https://chromewebstore.google.com/detail/playwright-extension/mmlmfjhmonkocbjadbfplnigmagldckm) in your everyday desktop Chrome or Edge, choose the browser in Settings → Connectors, and allow the connection. Website sign-in remains subject to that website's checks.

CloudCLI stays at **1.37.3**; Node.js stays at **24.19.0**. Application accounts, browser profiles, tokens and conversation history are not included. This GitHub release does not publish a new npm launcher package.
