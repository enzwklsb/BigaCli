# BigaCli 1.2.0

Windows desktop control and smaller updates, with fixes for permissions and interrupted replies.

- Inspect Windows apps, take screenshots, click and type through Cua Driver. Permissions follow the current Codex session. Background control depends on the target application.
- Download only new or changed files, reuse dependencies, exclude obsolete files from the new app, and retain the previous version for rollback.
- Read permission profiles from Codex CLI; keep partial replies after stopping and refreshing.
- Scroll the model list independently; show the processing hint after visible reasoning pauses for one second.

## Download and upgrade

**New installation:** extract `BigaCli-win-x64.zip` fully and run `start.cmd`. Windows 10/11 x64.

**Existing 1.1.0 or older:** download **`BigaCli-updater-win-x64.zip`**. Once tasks finish, close BigaCli's service window. Extract this small archive into your existing installation folder, alongside `active.json`, replacing the included launcher files. Run `start.cmd`, then install 1.2.0 from the update prompt. This one-time upgrade enables file-level downloads; no full installation download is required.

The desktop driver adds approximately 12 MiB compressed on first installation and is reused when unchanged. Updates download entire changed files, not binary diffs. Node, Codex and CloudCLI versions are unchanged. Component archives and file indexes are update assets, not standalone installers.

Verified on Windows 10: real Codex desktop approval and app inspection, Notepad input, Calculator background click, and cleanup after forced process termination. Administrator and lock-screen access are not promised. Use the supplied start.cmd (Windows PowerShell 5.1); do not substitute PowerShell 7 as the process-group host.
