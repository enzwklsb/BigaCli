BigaCli 的首个 Windows x64 可直接运行版本。

- 下载 `BigaCli-win-x64.zip`，解压后双击 `start.cmd`，打开 3101。
- 保留现有 UI、多账号及流式回复，新增应用内更新入口。
- 新版本发布后，已打开的页面会自动显示提示；点击一次完成组件更新。
- 内置 CloudCLI 1.37.2、Codex 0.146.0、Node 24.19.0。此基线尚不支持 Astra，请选择 Sol。
- 应用、依赖、Node 分组件分发；初次安装只需完整 ZIP。
- 源码采用 AGPL-3.0-or-later；请参阅仓库 README 和 LICENSE。
