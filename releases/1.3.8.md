BigaCli 1.3.8 restores compressed Codex conversation history and makes model capacity and retry messages visible in chat.

- Updated the bundled Codex CLI, SDK, and Windows runtime to 0.167.1.
- Added copy buttons to code blocks and block quotes.
- Raised the attachment limit to 512 MB, clarified disk-space errors, and removed uploaded copies when pending attachments are discarded. Files selected on the host can be referenced in place. The preview limit remains 20 MB.
- Fixed image download and open-on-PC buttons after closing a regular file preview.

For Windows x64, download `BigaCli-win-x64.zip`, extract it, and run `start.cmd`. Existing users can check for updates in Settings.
