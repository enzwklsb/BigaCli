# BigaCli

面向手机与电脑协同作业的 Codex Web 客户端，支持多账号会话接续、手机端额度重置、文件预览下载和可编辑消息队列。

**首次使用：下载下方 `BigaCli-win-x64.zip`，解压后运行 `start.cmd`。**

在浏览器打开 `http://localhost:3101`，登录自己的 Codex 账号。跨网络连接手机与电脑推荐使用 Tailscale；BigaCli 本身不提供网络穿透。

其他组件文件供应用内更新使用，无需手动下载。使用方法见 [README](https://github.com/enzwklsb/BigaCli#readme)。
